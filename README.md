# Blacklight Retribution


Server Emulator for BLR Steam Ver.



# Done
* Wrong username/password validation
* Nickname already exists
* Create Character
* Currencies (ZCoins & GP)
* EXP
* Rank
* Prestige Mode
* Inventory
* Shop

# Gameplay Stuff
* Third Person Support
* True FPS (Legs &  Feet visible)
* FOV & Viewmodel FOV changer
* HUD Sway / Parallax
* Self Player shadow visible
* Custom Content (Characters)
